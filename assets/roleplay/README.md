# Illustrations narratives publiques

Images optimisées pour le site et les aventures ChatGPT. **Aucun fichier image n'est encore publié dans ce répertoire.**

Organisation conseillée : `ports/`, `lieux/`, `portraits/`, `rencontres/`.

N'ajouter que des images validées, conformes au canon et sans spoiler. Format WebP privilégié pour alléger le chargement. Avant d'ajouter une entrée `ready` au manifeste `data/illustrations.json`, vérifier que le fichier correspondant existe et qu'il est visible sans authentification.

Les assets présents dans `nathanmon/battlecry` (privé) ne deviennent pas publics par simple référence ici.
