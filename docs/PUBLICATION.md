# Mise en ligne sur GitHub Pages

Le dépôt public `nathanmon/aventures-partagees` a été créé le 17 octobre 2026 et les fichiers du portail ont été poussés via le connecteur GitHub.

## Activer Pages

Dans le dépôt GitHub, ouvrir **Settings → Pages**. Sous **Build and deployment**, sélectionner :

- **Source** : Deploy from a branch
- **Branch** : main
- **Folder** : /(root)

Puis cliquer **Save** et attendre la publication.

Adresse attendue, à vérifier après activation : https://nathanmon.github.io/aventures-partagees/

Le connecteur GitHub utilisé ne permet pas de modifier directement les réglages GitHub Pages : cette étape reste manuelle.

## Contrôles

1. Ouvrir l'accueil, les pages de lore et la galerie sans être connecté.
2. Vérifier le chargement de `data/illustrations.json`.
3. Publier une première illustration WebP validée et mettre son statut à `ready`.
4. Tester l'ouverture de son URL directe.
5. Tester sa réutilisation dans une conversation ChatGPT : aucune intégration automatique n'est garantie.

## Confidentialité

Ne jamais publier de document contenant des secrets MJ, des données privées de joueurs ou des événements non validés. Pour les secrets, utiliser le dépôt privé `nathanmon/battlecry` et les fichiers non publics autorisés du projet ChatGPT.
