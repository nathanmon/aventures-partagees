Guide d'intégration

Vivre une aventure dans ChatGPT

Ce site héberge des documents publics et des images. Le jeu narratif se déroule dans ChatGPT : GitHub Pages ne devient pas automatiquement un moteur de conversation.

Étape 1

Préparer le projet ChatGPT

Configurer les instructions générales du maître du jeu et joindre les documents de lore pertinents, en conservant les secrets MJ dans des sources non publiques.

Étape 2

Choisir son aventure

Le joueur précise son univers, son personnage et ses préférences de dés. Le récit commence au lieu approprié, sans imposer une quête.

Étape 3

Afficher les images

Le MJ sélectionne une scène dans le catalogue et utilise son URL. Tester l'affichage intégré : un lien n'impose pas que ChatGPT restitue automatiquement l'image.

Confidentialité : les pages et les assets de ce site sont publics. Aucun document contenant les révélations réservées au MJ ne doit être publié ici. Une mise à jour GitHub Pages ne met pas automatiquement à jour les fichiers joints au projet ChatGPT.

Les fichiers de configuration disponibles dans le dépôt sont dans chatgpt/. Les sources du jeu vidéo et les biographies canoniques complètes demeurent dans le dépôt privé Battlecry.

Outils adaptés à l'aventure, sans perturber le rythme du récit.
